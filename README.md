### 🗃️ Open datasets for thermal energy storage

| Repository | What's inside |
| --- | --- |
| [**PCM_latent_storage_dataset**](https://github.com/christophersathya-bit/PCM_latent_storage_dataset) | 766 solid–liquid phase change materials + 197 composites (−74 °C to 1085 °C), each with source and quality flag. ML-ready and CFD-ready tables. CC BY 4.0, citable. |
| [**ss-pcm-dataset**](https://github.com/christophersathya-bit/ss-pcm-dataset) | Solid–solid phase change materials: transition temperatures, latent heats and sources, with ML descriptors |
| [**thermochemical-energy-storage-database**](https://github.com/christophersathya-bit/thermochemical-energy-storage-database) | 65 thermochemical storage materials and reactions, with classification, a 1D reactor model, an OpenFOAM packed-bed case and ML models |
| [**sensible-heat-storage**](https://github.com/christophersathya-bit/sensible-heat-storage) | 15 sensible-heat storage media from 0 to ~2000 °C, plus 3,000 synthetic storage cases |
